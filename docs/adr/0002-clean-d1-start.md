# ADR-0002: Чистый старт D1 без миграции Firebase-данных

- Статус: принято
- Дата: 2026-08-29

## Контекст

Владелец продукта подтвердил, что старые опросы и ответы не нужны. Их перенос увеличил бы риск, сроки и объём проверок без продуктовой ценности.

## Решение

Создать новую D1 schema и начать Vecta с пустой production database. Firebase-данные не импортировать. При необходимости допускается read-only архив вне Git перед окончательным отключением Firebase.

## Последствия

- Phase 10 является retirement, а не data migration.
- Converter и dual-write не создаются.
- После подтверждения Cloudflare runtime Firebase SDK, конфигурация и rules удаляются.
