# ADR-0003: Режимы участия и видимость результата

- Статус: принято
- Дата: 2026-08-29

## Контекст

Открытый вход удобен для массового использования, но не может строго идентифицировать человека без аккаунта. Корпоративные тесты также требуют контролируемой одноразовой попытки.

## Решение

Поддержать два режима: открытый по общей ссылке/коду и контролируемый по персональному одноразовому токену. Результат участника скрыт по умолчанию. При явном включении организатором показываются только `score/maxScore`, без answer key.

## Последствия

- D1 и API должны хранить access policy, invitation и attempt identity.
- UI обязан объяснять, что строгая уникальность обеспечивается только контролируемым режимом.
- Participant DTO никогда не содержит правильные ответы.
