# Vecta — Design Tokens

Статус: Phase 3 final candidate

Дата: 2026-08-30
Источник истины для runtime: `src/vecta/vecta.css`

## Принципы

- Светлая спокойная рабочая среда без неона, glassmorphism и декоративной геометрии.
- Синий используется для навигации и основных действий, но не как сплошной декоративный фон.
- Зелёный означает успешное завершение, оранжевый — внимание, красный — destructive-действие или блокирующую ошибку.
- Белые поверхности отделяются тонкой холодной границей; тени применяются только к плавающим слоям и ключевым карточкам.
- Phosphor Icons — единственный набор интерфейсных иконок. Emoji и текстовые символы вместо иконок не используются.

## Цвет

| Token | Значение | Назначение |
| --- | --- | --- |
| `--canvas` | `#f7fbff` | фон приложения |
| `--surface` | `#ffffff` | карточки, панели, модальные окна |
| `--ink` | `#142540` | основной текст |
| `--ink-soft` | `#52627c` | вторичный текст |
| `--muted` | `#77859d` | подписи и metadata |
| `--line` | `#dce7f5` | границы и разделители |
| `--blue-50…600` | `#f3f8ff…#1768e5` | основной акцент и состояния controls |
| `--green` / `--green-soft` | `#2eaf68` / `#e9f8ef` | успех и завершённые состояния |
| `--orange` / `--orange-soft` | `#f08a28` / `#fff2e4` | предупреждение без destructive-смысла |
| `--violet` / `--violet-soft` | `#835de8` / `#f0ebff` | дополнительная категоризация |
| `--danger` / `--danger-soft` | `#b94b43` / `#fff5f4` | удаление, выход с потерей попытки, ошибки |
| `--warning` / `--warning-soft` | `#9c671a` / `#fffbf1` | ограничения локального mock и важные пояснения |

Контраст основного текста и controls проверяется для светлого фона. Цвет не является единственным носителем состояния: используются подпись, иконка или статус.

## Типографика

- Семейство: `Manrope`, локально через `@fontsource`; fallback — `Segoe UI`, `sans-serif`.
- Доступные веса: 400, 500, 600, 700.
- Основной текст: 12–14 px, line-height 1.5–1.65.
- Metadata и вспомогательные подписи: 9–11 px; они не используются для критически важной инструкции без более крупного заголовка.
- Заголовки рабочих экранов: 28–36 px.
- Hero: `clamp(40px, 4.2vw, 62px)`.
- Letter spacing уменьшается только у крупных заголовков и логотипа.

## Пространство и размеры

Базовый шаг — 4 px. Допустимая шкала: `4, 8, 12, 16, 20, 24, 32, 40, 48, 64` px.

- Минимальная высота основной кнопки: 46 px.
- Icon button: 44 × 44 px.
- Touch target на мобильных ключевых действиях: не менее 44 px.
- Максимальная ширина рабочих поверхностей: 1240–1380 px в зависимости от задачи.
- Основные responsive breakpoints: 1180, 900 и 620 px.

## Радиусы и elevation

| Token | Значение | Применение |
| --- | --- | --- |
| `--radius-sm` | `8px` | inputs и компактные controls |
| `--radius-md` | `9px` | buttons, options, внутренние панели |
| `--radius-lg` / `--radius` | `12px` | карточки, drawers, dialogs |
| `--radius-pill` | `999px` | badges и status pills |
| `--shadow-control` | мягкая синяя тень | primary CTA |
| `--shadow-float` | `0 16px 44px rgba(34,80,145,.14)` | menu, modal, drawer |

## Состояния controls

- Hover меняет цвет/границу, но не перестраивает layout.
- Focus: видимый синий ring толщиной 3 px с offset 2 px.
- Disabled: `opacity: .5`, курсор `not-allowed`; действие остаётся подписанным.
- Loading: текст действия меняется на глагол в процессе, повторное нажатие блокируется.
- Error: объясняет, что произошло и как исправить; локальный ввод не удаляется.
- Destructive: красная кнопка используется только после отдельного подтверждения.

## Motion

- Быстрый feedback: `--motion-fast` = 160 ms.
- Стандартный transition: `--motion-base` = 180 ms.
- Drawer: около 200 ms.
- Графики в QA не анимируются, чтобы первый рендер был стабильным.
- `prefers-reduced-motion: reduce` отключает необязательные анимации и плавную прокрутку.

## Применение

- Новые поверхности сначала используют существующие tokens и компоненты.
- Новый цвет, радиус или breakpoint добавляется только при отсутствии семантически подходящего текущего значения.
- На Phase 4 допускается механический рефакторинг оставшихся literal-значений в CSS-переменные без визуального изменения.
